# Portfolio Ange Teufack

Portfolio personnel d'Ange Teufack, etudiant ingenieur oriente Data, IA, IoT et developpement web.

## Objectif

Ce projet a pour but de presenter un portfolio statique, professionnel et publiable via GitHub Pages pour mettre en avant :

- le profil etudiant ingenieur
- les competences techniques
- les projets personnels et academiques
- les experiences et certifications
- les moyens de contact

## Technologies utilisees

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
- GitHub Pages

## Ouvrir le projet en local

1. Ouvrir le dossier du projet dans VS Code ou dans un autre editeur.
2. Ouvrir `index.html` dans un navigateur.
3. Verifier que `css/style.css` et `js/main.js` se chargent correctement.
4. Tester le responsive avec les outils developpeur du navigateur.

## Publication avec GitHub Pages

1. Pousser le projet dans un depot GitHub.
2. Verifier que `index.html` reste a la racine du depot.
3. Ouvrir GitHub, puis aller dans `Settings`.
4. Aller dans la section `Pages`.
5. Dans `Build and deployment`, choisir `Deploy from a branch`.
6. Selectionner la branche de publication, en general `main`.
7. Selectionner le dossier `/ (root)`.
8. Enregistrer avec `Save`.
9. Attendre que GitHub genere l'URL publique du site.
10. Ajouter ensuite cette URL dans les balises SEO du fichier `index.html`.

## Remarques

- Le portfolio utilise actuellement des placeholders visuels tant que les vrais assets ne sont pas encore ajoutes.
- Les projets insuffisamment documentes peuvent etre masques temporairement pour eviter un rendu incomplet.
- Le formulaire de contact fonctionne en mode `mailto:` tant qu'aucun backend ou service tiers n'est configure.
